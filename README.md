# Kapravah Studio recreation

A standalone, responsive static recreation of the supplied interior-studio reference.

Open `index.html` in a browser, or serve this directory with any static server:

```sh
python3 -m http.server 4173 --directory /path/to/kalpravah-studio
```

Then visit `http://localhost:4173`.

Included interactions:

- Loading introduction, sticky navigation, mobile menu, and smooth anchor scrolling
- Selected-work filters and a working portfolio carousel
- Responsive desktop/mobile layouts and scroll-reveal motion
- Placeholder feedback for WhatsApp and enquiry calls to action

The photographs and logo intentionally reference the supplied public site so the visual match can be assessed. Replace the image URLs in `script.js` and `index.html` with licensed project assets before production deployment.
